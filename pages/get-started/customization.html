Layers

Goldilocks-CSS is designed to allow customization of the theme through the use of layers. CSS layers make the cascade order explicit and let defaults, components, helpers and project overrides coexist without specificity tricks. The layer order is reset, tokens, base, elements, layout, extended, extras, utilities and custom:

  • Reset: normalizes browser defaults;
  • Tokens: provides the default design variables and theme values. Keeping defaults in a layer means an unlayered stylesheet or a later layer can override them without !important;
  • Base: sets up global HTML styles and foundations;
  • Elements: styles typography, buttons, forms, tables, images and other common elements;
  • Layout: defines layout primitives and responsive helpers;
  • Extended: defines common components such as accordions, breadcrumbs, cards and navigation;
  • Extras: defines additional elements and components such as progress bars, modals, popovers and charts;
  • Utilities: contains helper classes. It comes after component layers, so utilities override their normal declarations without !important;
  • Custom: reserved for project overrides and additions. Later normal layers take precedence over earlier ones.

Re-theming

The palette uses hue custom properties for primary, secondary, complement, grey, link, success, warning and danger colours: --p-h, --s-h, --c-h, --g-h, --lnk-h, --ok-h, --warn-h and --err-h. Change a hue in the later custom layer to generate a coordinated palette, or override individual palette or semantic tokens instead. 


@layer custom {
    :root {
        --p-h: 300;
        --s-h: 165;
    }
}

Use css/theme-template.css as the starting point; it lists the default hue values and the palette and semantic tokens that can be overridden. Load your customized theme stylesheet after the Goldilocks-CSS bundle. View the theme template.
